하츠네 미쿠 · Miku Desktop
Windows 10/11, x64

실행
MikuDesktop.exe를 더블 클릭합니다. 설치와 관리자 권한이 필요 없습니다.
스프라이트는 실행 파일에 포함되어 있습니다.
Windows 기본 .NET Framework 4.x를 사용합니다. 별도 브라우저나 Node/Python이 필요 없습니다.

조작
• 다른 앱에서 키보드를 입력하면 8번 생각·집중 동작만 보여 줍니다.
  마지막 키 입력부터 기본 1.5초 동안 유지합니다. Shift/Ctrl/Alt/Windows 키 단독 입력은 제외합니다.
  마지막 입력 후 1.5초가 지나면 남은 프레임을 기다리지 않고 바로 전환합니다.
  동작 사이에 보간 프레임은 없습니다.
• 대기 동작의 첫 번째 원본 스프라이트는 사용하지 않습니다. 나머지 5프레임을 재생합니다.
• 가만히 있을 때 눈 깜빡임은 약 5.3초마다 한 번입니다.
• 마우스를 움직이면 커서 방향을 바라봅니다. 마지막 이동 후 기본 1초 동안 유지합니다.
  16방향 시선이며 작은 움직임과 방향 경계에는 흔들림 방지 처리가 있습니다.
• 미쿠에 커서를 올려 두면 점프를 반복합니다. 커서를 떼면 진행 중인 점프를 착지까지 마칩니다.
• 미쿠를 왼쪽 버튼으로 잡아 끌면 이동 방향에 따라 좌우로 달립니다.
  드래그 중에는 점프하지 않습니다. 이동을 멈추면 짧은 정지 감지 시간(약 0.16초) 후 바로 대기로 전환합니다.
  드래그 시작·방향 변경은 즉시 반영합니다.
  점프만 착지까지 마친 뒤 전환하며, 다른 애니메이션은 행동이 끝나면 바로 전환합니다.
• 작업 표시줄을 제외한 화면 안에서만 움직입니다.
  위쪽은 점프 최고점의 가장 높은 픽셀이 작업 영역 위 경계에 닿도록 제한합니다.
  좌우 고정 여백은 없습니다. 가장 넓은 동작의 실제 픽셀이 작업 영역 끝에 닿도록 제한합니다.
  좁은 동작에서는 머리카락 폭 차이만큼 여유가 생길 수 있습니다.
  위쪽 작업 표시줄이 있으면 그 아래 경계를 기준으로 합니다.
  아래쪽은 발끝을 기준으로 제한해 작업 표시줄 바로 위에 붙일 수 있습니다.
  창 아래의 투명 여백은 겹칠 수 있지만 미쿠의 보이는 부분은 작업 표시줄 안으로 내려가지 않습니다.
• 투명한 부분은 뒤에 있는 앱을 클릭할 수 있습니다.
  미쿠를 클릭하거나 드래그해도 입력 중인 앱의 포커스를 가져오지 않습니다.

메뉴
작업 표시줄에 앱 창 버튼이 생기지 않습니다. Alt+Tab 목록에도 나타나지 않습니다.
오른쪽 아래 알림 영역의 ^(숨겨진 아이콘 표시)를 열어 미쿠 얼굴 아이콘을 찾으세요.
트레이 아이콘을 클릭하거나 오른쪽 클릭하면 메뉴가 열립니다. 미쿠 자체를 우클릭해도 메뉴는 열리지 않습니다.
알림 영역에서 아이콘이 ^ 안에 들어갈지 직접 보일지는 Windows 설정에 따릅니다.

• 일시정지: 미쿠를 정지시키고 입력 감지를 끕니다.
• 미쿠 숨기기 / 다시 표시: 트레이 아이콘을 남기고 미쿠를 숨깁니다.
• 크기: 50%, 75%, 100%, 125%, 150%, 200%.
  Windows 화면 배율에 관계없이 100%는 실제 192×208픽셀입니다.
• 타이핑 종료 대기: 1.0 / 1.5 / 2.0 / 3.0초.
• 시선 유지 시간: 0.5 / 1.0 / 1.5 / 2.0초.
• 항상 위에 표시: 켜기 / 끄기.
• 위치 초기화: 기본 모니터의 오른쪽 아래 안전한 위치로 돌아갑니다.
• 종료: 앱과 트레이 아이콘을 종료합니다.

기본 우선순위
드래그 → 커서를 올린 동안 반복 점프 → 타이핑 집중 → 시선 추적 → 기본 대기.
커서를 뗀 뒤 이미 떠 있는 점프는 착지까지 마칩니다.
트레이 메뉴를 열어 둔 동안에는 새 점프와 입력 반응을 시작하지 않습니다.

설정과 이동
위치, 크기, 대기 시간, 항상 위에 표시 설정은 실행 파일 옆의
MikuDesktop.settings.ini에 저장됩니다. 쓰기 가능한 폴더에서 사용하세요.
숨김/일시정지는 재실행 시 해제됩니다. Windows 시작 시 자동 실행은 등록하지 않습니다.
앱을 다시 실행하면 새 창을 만들지 않고 기존 미쿠를 다시 표시합니다.
중복 실행은 같은 Windows 데스크톱 안에서만 제한합니다. 격리된 검증 실행은 실제 화면 실행을 막지 않습니다.
모니터를 분리하거나 화면 배율/작업 표시줄 위치를 바꾸면 안전한 화면 영역으로 보정합니다.
다중 모니터에서 실제 픽셀 크기와 잡은 지점을 유지합니다. 각 모니터의 작업 영역에 맞춥니다.
선택한 크기가 화면보다 크면 화면의 안전한 영역에 맞도록 자동으로 축소합니다.

성능과 입력
PNG는 한 번만 디코딩하고 사용 중인 원본 48프레임을 캐시합니다.
타이핑에 사용하지 않는 기다림·검토 프레임은 캐시하지 않습니다.
대기는 5.3초 주기의 느린 깜빡임을 사용합니다.
그 외 동작은 원본 애니메이션 간격을 유지하며 매 프레임 이미지 파일을 읽지 않습니다.
마우스 반응은 약 30Hz로 합쳐 처리하고 드래그는 최대 약 60Hz로 갱신합니다.
숨김/일시정지 상태에서는 Raw Input 등록과 애니메이션 타이머를 중지합니다.
키 입력 발생 시점만 사용합니다. 글자 변환, 입력 내용 저장, 네트워크 통신은 없습니다.
보안 데스크톱(UAC 화면 등)에서는 입력에 반응하지 않을 수 있습니다.

소스
source 폴더에 C# 소스, 스프라이트, 아이콘, 매니페스트와 build.ps1이 있습니다.
build.ps1은 Windows 기본 C# 컴파일러로 실행 파일을 빌드합니다.
이 앱의 위치 제한은 사용자 요청을 구현한 것입니다. Codex Mini 내부 구현과 동일한 코드는 아닙니다.
원본 ChatGPT Pet의 활성화 상태는 변경하지 않습니다.
